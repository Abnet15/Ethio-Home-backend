# Security Policy

We take security seriously. Please report vulnerabilities privately; do not open public issues.

## Reporting
- Email: sisayabnet49@gmail.com
- Include: impact, affected versions/paths, reproduction steps, and any suggested mitigations
- We acknowledge within 3 business days

## Disclosure
- We validate within 7 days
- Fix timeline is priority-based (typically <= 30 days)
- We coordinate disclosure and credit upon release

## Report Template
```
Title: <short summary>
Affected: <paths, versions>
Impact: <what can happen>
Repro: <steps, PoC>
Mitigation: <ideas if any>
```

## Hardening Practices
- Dependencies updated regularly
- Helmet, CORS, rate limiting enabled
- Central validation and error handling
- Secrets in environment variables only
